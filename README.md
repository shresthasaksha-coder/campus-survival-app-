# campus-survival-app
Campus Survival App for UNT students

## Project Purpose
The purpose of this project is to help students who are new to UNT or Denton find important campus resources, services, and useful information in one place.
## Planned Features
- Welcome and guest access
- User registration and login
- Home and Explore pages
- Search feature
- Housing information
- Dining and grocery information
- Campus resources
- Safety and Help page
- Saved items
- User profile and preferences
## Project Structure
- `frontend/` - User interface and pages
- `backend/` - API, database, and server-side logic
- `docs/` - Project documentation and design files
## Current Status
The project planning and setup phase is in progress.
